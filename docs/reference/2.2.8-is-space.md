## Recognize C whitespace

Whitespace is a small, explicitly defined set of character values. For this
subtask, `is_space` recognizes the six C-locale whitespace characters:

| Character | Escape | Result |
|---|---|---:|
| space | `' '` | 1 |
| horizontal tab | `\t` | 1 |
| line feed | `\n` | 1 |
| vertical tab | `\v` | 1 |
| form feed | `\f` | 1 |
| carriage return | `\r` | 1 |

Other bytes are not whitespace here. For example, `is_space('a')`,
`is_space('\0')`, and `is_space((char)-1)` return `0`.

```text
character ──is_space──> 1 (one of six values) or 0 (anything else)
```

Writing the comparisons directly keeps this predicate pure and avoids relying
on the disallowed `isspace` library function. The range from tab through
carriage return covers the five contiguous control characters in the set;
space is checked separately. The signed `char` case also stays safely outside
that range.

## How it was planned

The approved scope added one generic core predicate in `coders/src/utils/`,
declared its public prototype in the Utils section of `main.h`, and added its
source to the deliverable Makefile. Acceptance criteria cover all six accepted
characters, representative rejected values including a negative `char`, the
prototype order, and a clean build with no relink plus Norm. The predicate has
no caller yet; the next subtask switches `trim_slice` to use it.

<!-- section: execution -->
## How it was executed

The implementation uses explicit comparisons: a direct check for space and a
contiguous range check for tab through carriage return. This expresses the
contract without an external classification function and handles negative
`char` values without indexing or conversion. The function has no I/O,
allocation, or state, so it can be reused by the utility that trims text.
