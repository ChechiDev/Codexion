## Description

`int get_target_met(t_sim *sim, int *met)` in
`coders/src/monitor/get_target_met.c`: tells the monitor (8.2.1) whether the
run has reached its end condition. Subject: the simulation stops when every
coder compiled at least `number_of_compiles_required` times; PLAN.md "Edge
cases": 0 required ends immediately and cleanly.

**Contract.** Validate; if `number_of_compiles_required` is 0, `*met = 1` at
once; else for each coder in order lock its mutex, read `compile_count`,
unlock, and stop at the first coder below target. `*met` is 1 iff every coder
has `compile_count >= number_of_compiles_required`, else 0. Reading the
counts one at a time is sound: a count only grows (`set_compile_count`, 7.1.2,
counts completed compiles only), so "every coder reached it" stays true once
observed. 0 on success; -1 on NULL input, no coders, lock failure or unlock
failure; `*met` unchanged on every -1.

**Preconditions.** The simulation was built by `init_simulation` (coder
mutexes initialised) from a configuration validated by `parse_config` and not
changed afterwards; `met` points to storage that is not a field of a coder or
the simulation; the caller holds no coder mutex.

**Lock order.** Each coder mutex is a leaf: at most one is held at a time and
nothing else is locked while it is held.

**Name.** `get_` reads or computes a value without changing anything
(`docs/conventions.md`); not `is_`, which must return 0 or 1. Checked: no
`get_target_met` exists in `tests/` or `coders/`.
