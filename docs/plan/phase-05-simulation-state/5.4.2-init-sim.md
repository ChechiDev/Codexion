## Description

`int init_simulation(t_sim *sim, const t_config *config)` in
`coders/src/init/init_simulation.c`: builds the whole simulation state from the
validated arguments (phase 02), ready for phase 09 to start the threads.

**Sequence.**
1. Validate: `sim` and `config` non-NULL, `config->number_of_coders >= 1`.
   Nothing is written before this passes.
2. Plain fields: copy `*config` into `sim->config`; `start_ms = 0` (phase 09
   sets it when the threads start), `stopped = 0`, `next_ticket = 0`,
   `dongles = NULL`, `coders = NULL`.
3. Mutexes: `stop_mutex`, `log_mutex`, `ticket_mutex`. If one fails, the ones
   already initialised are destroyed in reverse and it returns -1.
4. `init_dongles(&sim->dongles, n)` (5.2.4).
5. `init_coders(&sim->coders, sim, n)` (5.3.4): each coder gets the back
   pointer to `sim`.

**Rollback.** Steps 4 and 5 roll themselves back and leave their out-pointer
untouched (still NULL) on failure, so after step 3 every failure is a single
`free_sim(sim)` (5.4.1), which skips the NULL array, frees the other, and
destroys the three mutexes. Nothing stays allocated or initialised after -1.

**Return contract.** 0 on success; -1 on invalid input (`*sim` untouched) or
on any failure (contents of `*sim` unspecified, nothing live). The caller never
calls `free_sim` after -1.

**Ownership.** On 0 the caller owns everything and releases it with
`free_sim(sim)` once every thread has been joined (phase 09). `config` is read
only and copied. Precondition: `sim` owns no live resource (no previous field
is read, AC4).

Adapter (PLAN.md layers: `init`/`cleanup` own the mutex/cond/alloc lifecycle).
Close-time documentation: the `init/` row of `docs/architecture.md` mentions
it, with the init order and the rollback.

**README.** No close-time update (no user-visible change until phase 09).

**Name.** The public name is `init_simulation`, not `init_sim`: seven sealed
oracles of phase 03 (`test_3.2.1.c`, `3.2.2`, `3.3.1`, `3.4.3`, `3.4.4`,
`3.4.5`, `3.4.6`) define a local `static init_sim` helper that would clash
with a `main.h` prototype, and `migrates:` is only available to issue
subtasks. Unit tests whose local helper clashed rename it to `setup_sim`.
The stale `coders/src/init/init_sim.c` of the first attempt is deleted by the
user by hand (agents cannot delete under `coders/`).
