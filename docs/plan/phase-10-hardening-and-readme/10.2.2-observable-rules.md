`S` is the timing slack in ms read from `CODEXION_TIME_SLACK_MS` (default 0; CI exports 40), added to the log upper bound only. It is a CI tolerance, not evidence of the subject's 10 ms limit. `C` is `time_to_compile` and `D` is `dongle_cooldown`.

Test notes for the oracle: AC5 uses a lower bound because the release is not logged: the holder's `is compiling` timestamp plus `C` is never later than the real release. The exact fifo/edf request order cannot be inferred from the log, since request arrival is not logged; it stays covered by the sealed API-level oracles of phase 06, and AC6 only checks alternation.
