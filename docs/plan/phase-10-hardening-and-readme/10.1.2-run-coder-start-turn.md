## Description

`run_coder` applies the one-time start-up offset of 10.1.1 before its first
dongle request, so odd seats usually queue first and non-neighbouring coders
compile in parallel from the start. Only the start changes: the cycle, the logs
and the fifo/edf arbitration stay the same.

A stop during the offset exits cleanly (`res` is 1, nothing is held), and an
error (-1) follows the existing failure path of `release_run`.

**README.** Declared in `files:` as a living file (AGENTS.md), as earlier
subtasks did. Codex updates it at close, not the implementer, so it is not an
acceptance criterion: why even seats start 1 ms later, that it is a heuristic,
and that `START_TURN_MS` in `coders/main.h` is the single place to change it.
