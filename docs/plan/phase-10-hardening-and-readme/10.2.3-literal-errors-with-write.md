## Description

GCC turns `fprintf(stderr, "fixed text")` into `fwrite`, which is outside the
subject's allowed list (6.1), so the delivered binary shows that symbol today.
Passing the text through `"%s"` does not avoid it (measured with cc 13.3). `write`
and `strlen` are allowed, and a scratch build with them removes the symbol. The
output bytes do not change.

Only `print_arg_error`'s fixed scheduler message moves to `write`: the message
of positions 1..7 uses real formatting and stays a `fprintf`, which the compiler
leaves as it is.

**Sealed oracles.** Those that check these messages (`test_2.2.1`, `test_2.4.1`,
`test_9.5.1`, among others) are checked with `make check` right after the plan
gate; the bytes are the same, so none is expected to change.
