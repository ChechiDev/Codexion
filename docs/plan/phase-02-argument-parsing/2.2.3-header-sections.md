## Description

Applies the `main.h` layout from `docs/conventions.md` to the current header.
Pure reordering plus section titles; nothing is renamed or added. Each
prototype goes in the section of the `src/` folder that defines it
(`trim_span` lives in `utils/` since 2.2.2).

Target shape:

```c
#ifndef MAIN_H
# define MAIN_H

/* ---- Macros ---- */

# define EXIT_USAGE 1

/* ---- Types ---- */

typedef enum e_mode ... t_mode;
typedef struct s_config ... t_config;
typedef struct s_span ... t_span;

/* ---- Utils ---- */

t_span	trim_span(const char *str);

/* ---- Parsing ---- */

int		parse_number(const char *str, int *out);

/* ---- CLI ---- */

void	print_usage(void);

#endif
```

- No `Main` section: `main.c` exports nothing besides `main`.
- Within a section, keep the dependency order (a type before the types that
  use it).
- Refresh the `Updated:` header line.
- The names `t_span`/`trim_span` are kept here on purpose; 2.2.4-2.2.7 replace
  them with `t_slice`/`trim_slice`. AC1-AC2 avoid naming them (and avoid closed
  lists) so this oracle stays valid through the rename and later phases.
