## Description

First generic predicate in `coders/src/utils/` (rules in `docs/conventions.md`):

```c
int	is_space(char c);
```

- Whitespace is the six C-locale `isspace` characters (same set as 2.1.1);
  `isspace` itself is not an allowed function. Returns 1 or 0.
- No clash with an old `static is_space`: `trim_span.c` dropped it in 2.2.6
  and is gone since 2.2.7; `trim_slice.c` never had one.
- No caller yet: `trim_slice` switches to it in 2.2.9.
- Order inside Utils: predicates first, then the helpers that use them.
