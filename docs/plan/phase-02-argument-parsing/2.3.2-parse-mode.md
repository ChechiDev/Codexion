## Description

`int parse_mode(const char *str, t_mode *out)` in its own file
`coders/src/parsing/parse_mode.c` (core: no output, no pthread, no clock), one
unit per file so `parse_config` (2.3.3) stays small and modular.

The subject requires the scheduler to be **exactly** `fifo` or `edf`: comparison
is whole-string and case-sensitive with `strcmp` (allowed), with no trimming
(the roadmap review of 2026-10-27 rejected accepting other case or surrounding
whitespace). Prefix/suffix inputs are listed in AC2 so that a later switch to a
length-limited comparison would fail the tests.

Returns 0 and writes `*out` on a match; returns -1 and leaves `*out` untouched
otherwise, including `str == NULL` or `out == NULL`. `<string.h>` is included in
the `.c` file, not in `main.h`.

`depends: 2.3.1` only orders the shared `coders/Makefile` `SRC` edits; there is
no functional dependency.
