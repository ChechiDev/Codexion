## Description

`main` keeps the `argc != 9` check from 1.2.3 (usage only, status 1). With 8
arguments it calls `parse_config(argv, &config)` (2.2.3) on a local `t_config`:

- **Non-zero mask:** a `static` helper in `main.c` walks the mask from bit 1 to
  bit 8 and calls `print_arg_error(position)` (2.3.1) for each set bit, in
  argument order. Then `main` calls `print_usage()` once and returns
  `EXIT_USAGE` (1). Nothing is allocated and no thread exists at this point.
- **Zero mask:** for now `main` returns 0. Phase 09 replaces this with
  init/run/teardown; acceptance tests must not assert anything about a valid run
  beyond AC4 (status 0, empty stderr).

The mask walk lives in `main.c`, not in `cli/`: it is a few lines used only by
`main`, and AC1-AC3 cover it through the binary.

`README.md` (living file, `docs/conventions.md` rules): the Instructions part
gains the validation rules in plain words and one real multi-error run with its
exact stderr output.

> Input-normalisation rules may change in the future (user decision, 2026-10-27;
> see `PLAN.md`, Input validation).
