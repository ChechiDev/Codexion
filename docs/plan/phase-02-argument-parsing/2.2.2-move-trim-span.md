## Description

`coders/src/utils/` (`docs/conventions.md`). Pure move, no code change, so the
rest of the span → slice rename (2.2.4–2.2.7) happens entirely inside `utils/`
and `utils/` never depends on `parsing/`.

- `main.h` is not touched here: 2.2.3 creates the sections and places the
  `trim_span` prototype under Utils.
- Refresh the `Updated:` header line of the moved file and the Makefile.

Makefile lists `src/utils/trim_span.c`, and its content is unchanged apart from
the header.

span → slice rename, so this oracle never needs migrating. The old API itself
