## Description

`int parse_config(char **argv, t_config *config)` in its own file
`coders/src/parsing/parse_config.c` (core: no output, no allocation, no pthread,
no clock). `argv` is `main`'s argv; the caller has already checked `argc == 9`
(1.2.3), so it reads `argv[1]` to `argv[8]`.

- **No duplicated logic:** one `static int parse_field(const char *str,
  int position, int *out)` calls `parse_number` (2.1.2, which reuses
  `trim_slice`) and then checks `value >= get_arg_minimum(position)` (2.3.1, the
  single source of the minimums; no minimum is written here). It is called once
  per numeric field, positions 1..7 in the subject's order. Argument 8 goes
  through `parse_mode` (2.3.2).
- **Every argument is checked**: parsing never stops at the first failure, so
  the user sees all mistakes at once (user decision, 2026-10-27).
- Returns 0 when all eight are valid. Otherwise returns a bit mask where bit
  `n` (`1 << n`, `n` in 1..8) is set for each invalid argument `n`; bit 0 is
  never used. The mask is at most `0x1FE`, so `int` is enough. When the mask is
  non-zero, `*config` contents are unspecified and must not be used. 2.4.2 walks
  the mask in order 1..8 and prints one error line per set bit (2.4.1).

> Input-normalisation rules may change in the future (user decision, 2026-10-27;
> see `PLAN.md`, Input validation).
