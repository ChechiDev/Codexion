and since 2.2.6 `trim_span` is only a delegate, so it is removed.

- `coders/src/utils/trim_span.c` is deleted.
- `main.h`: `s_span`/`t_span` leave Types and the `trim_span` prototype leaves
  Utils. Refresh `Updated:`.
- `Makefile`: `src/utils/trim_span.c` leaves `SRC`. Refresh `Updated:`.
- Unit tests (Claude): `tests/unit/test_trim_span.c` is removed or rewritten
  as `test_trim_slice.c` (2.2.4 may already have added it).
- 2.1.1 stays as delivered (commit, spec, reference doc); this subtask
  supersedes its names.

Code review check: `coders/src/utils/trim_span.c` no longer exists and
`coders/Makefile` `SRC` does not list it.
