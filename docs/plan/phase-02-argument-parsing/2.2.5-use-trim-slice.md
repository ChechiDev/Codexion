## Description

Second step of the span → slice rename (2.2.4 added the new API): the only
caller of `trim_span` switches to `trim_slice`, so 2.2.7 can delete the old one.

- `parse_number.c`: `t_span span` becomes `t_slice slice`, and the call
  becomes `trim_slice(str)`. Overflow guard, digit check and contract do not
  change.
- Refresh the `Updated:` header line.

Code review check: `parse_number.c` no longer references `t_span` or `trim_span`.
