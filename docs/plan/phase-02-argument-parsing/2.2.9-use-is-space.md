## Description

**Structural refactor (no behaviour change)** — acceptance tests are regression
oracles (`AGENTS.md` §1); the structural goal is the `Code review check:` below.

Applies the rule "when a function can be written more cleanly with a utils
helper, use it" (`docs/conventions.md`) to `trim_slice`: the inline whitespace
condition from 2.2.6 is replaced by `is_space` (2.2.8), in both the leading and
the trailing loop.

- Only the whitespace test changes; `strlen`, the `int` cast and the contract
  stay as in 2.2.6.
- AC2 guards the classic mistake of a wrong range when switching helpers
  (eating `'\x01'` or `'\x7f'`).
- Refresh the `Updated:` header line.

Code review check: `trim_slice.c` calls `is_space` and no longer writes the
whitespace characters by hand.
