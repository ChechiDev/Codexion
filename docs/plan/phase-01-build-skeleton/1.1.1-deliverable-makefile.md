## Description

Create the deliverable build required by `docs/codexion-rules.md` §3.5-3.6 and §6.1.

`coders/Makefile`:
- `NAME = codexion`, `CC = cc`, `CFLAGS = -Wall -Wextra -Werror -pthread` plus
  `-I.` so future sources include `"main.h"`.
- Explicit `SRC` list (no wildcards, Norm style), objects next to their sources
  (`SRC:.c=.o`), so later subtasks add `src/<module>/<file>.c` lines to `SRC`.
- Rules: `all` (default, depends on `$(NAME)`), `$(NAME)`, `%.o: %.c`, `clean`,
  `fclean`, `re`; `.PHONY: all clean fclean re`. The header dependency is added
  in 1.2.1, when `main.h` exists.
- No relink: `$(NAME)` depends only on the objects; `all` has no recipe of its own.

`coders/main.c`: minimal `int main(void)` returning 0 (no include needed yet), so
the Makefile has something to build. 1.2.2 replaces it with the argument-count check.

`README.md` (rules: `docs/conventions.md` README section): mandatory first line,
the five mandatory sections as a skeleton, and a didactic Instructions part about
building only (what each rule does, why there is no relink). Running the program
is documented when it does something (1.2.2 onwards).

Every C file and the Makefile carry the 42 header (login `sperez-l`) and pass
`norminette`. Acceptance tests run `make` via `system()`/`popen()` from the repo
root and must leave `coders/` built (`make -C coders`) when they finish.
