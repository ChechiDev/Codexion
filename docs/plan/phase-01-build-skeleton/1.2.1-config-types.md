## Description

First content of the single header (living file).

- Include guard `MAIN_H`. **No system includes**: `t_policy` and `t_config` need
  none, and the core API stays free of platform headers (`docs/architecture.md`).
  Each later subtask adds the system header it actually needs, when it needs it.
- `typedef enum e_policy { POLICY_FIFO, POLICY_EDF } t_policy;` (names avoid
  `SCHED_FIFO`, which `<pthread.h>` defines).
- `typedef struct s_config { ... } t_config;` with the eight fields above, in the
  subject's argument order. `int` is enough because parsing (phase 02) caps every
  value at `INT_MAX`.

`coders/Makefile`: the pattern rule becomes `%.o: %.c main.h`, so any header
change recompiles the objects (and still no relink when nothing changed).

No functions, no globals. Later phases append their types (`t_request`, `t_heap`,
`t_dongle`, `t_coder`, `t_sim`) and prototypes to this header.
